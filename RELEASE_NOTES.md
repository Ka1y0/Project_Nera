# Nera 0.5.0 Alpha 2 — source preview

Repository: [Ka1y0/Project_Nera](https://github.com/Ka1y0/Project_Nera)

Experimental source-only preview of Nera's control plane, local CLI/stdio MCP bridge,
three-language resources and deterministic native safety policies. Includes current-session
first-frame guards and a cleanup model that distinguishes a clean release acknowledgement
from confirmed reclamation after an owned process exits.

**No working DLDR application or Portable binary is supplied.** The operational private
Feature18 adapter and proprietary Runtime are excluded while their applicable publication
permissions remain unresolved. Runtime distribution policy is user import, not bundling;
importing a Runtime cannot enable this stripped source subset. No face images, screenshots,
user files, secrets or internal Git history are included.

Managed and native contract tests are not proof of HDR/graphics performance or physical input
safety. Read the README and known limitations. This is not an NVIDIA-endorsed or Stable product.

## Source archive

The source archive includes the reviewed Windows runner tool-resolution fix and the
canonical language-selector ordering. Public preparation history has been normalized
with explicit project-owner authorization. The Alpha 2 tag and four source-preview
assets are regenerated from the clean public tree without changing the version or
creating a duplicate release. This does not clear the operational binary publication gate.

## Public documentation policy

Current repository documentation and release notes are English-only. Application localization
remains available in English, Simplified Chinese and Traditional Chinese.
